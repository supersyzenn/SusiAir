# Susi Air Pilot App Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Track completion with checkboxes.

**Goal:** Deliver the brief's working full-stack pilot application and verifiable deployment assets.

**Architecture:** Nuxt 3 client consumes a NestJS API. Nest loads the original JSON seeds at startup and owns all business calculations and status derivation.

**Tech Stack:** Nuxt 3, Vue, Pinia, SCSS, NestJS, TypeScript, JWT, Jest, Playwright, OpenAPI, Postman.

**Spec:** `docs/superpowers/specs/2026-10-29-pilot-app-design.md`

## Global Constraints
- Business date `2026-05-15`; no wall clock for business logic.
- Frontend `/nuxt`, backend `/nest`; no frontend business seed data.
- Preserve supplied chart bounds, limits, and duty colors.
- Protect every data endpoint; fixed credentials `johndoe` / `susiairtest`.

## Review Focus
- Calendar month transitions across years and rapid navigation must display the requested month.
- Expired JWT must clear private state and redirect to sign-in.
- Over-limit/overflow chart values must remain visible without stretching mobile layout.
- Malformed query dates and reversed intervals must produce consistent 400 responses.
- API outage must show an actionable retry, not a blank dashboard.
